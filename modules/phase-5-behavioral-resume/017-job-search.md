# Job search logistics

Start once the resume variants are ready ([016](016-resume-rewrite.md)). Applications take 2–6 weeks to reach an onsite, so send warm-up applications early and run the Phase 7 mocks in parallel. Back to [001-start-here](001-start-here.md).

**Done when:** a target list exists, referrals are requested, and the first applications are sent.

Apply to warm-up companies first, so the dream-company interviews come after practice.

## 2. Referral message (template)
> Hi <name>, I'm a senior engineer (.NET, distributed systems, Azure, GenAI) looking at the <role> role on <team>. <One line on why this team>. Would you be open to referring me, or to a 15-minute chat about the team? Resume attached. Thanks either way!

## 4. Recruiter screen
- [ ] **Pitch:** the 90-second "tell me about yourself" from [011](011-openers-motivation.md).
- [ ] **Salary expectations:** a range based on level data, or deflect ("I'd like to learn more about the level first; what's the band?"). See [018](018-negotiation.md).
- [ ] **Timeline:** when you can start; other processes in flight (creates urgency, never lie).
- [ ] **Ask:** which rounds the loop has (AI-assisted coding? code review? product architecture? behavioral?), and the level they're hiring for.
